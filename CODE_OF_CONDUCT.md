## Our Mission

ASTROVITAL AI exists to protect human life in deep space.
Every interaction with this project — code, issues,
discussions — must honor that mission.

---

## Standards

### Expected Behavior

- Treat all contributors and users with respect
- Use professional and constructive language
- Focus discussions on advancing space medicine research
- Give proper attribution when referencing this work
- Report issues accurately and honestly

### Unacceptable Behavior

- Unauthorized reproduction or redistribution of code
- Commercial use without written permission
- Plagiarism of innovations, methodology, or documentation
- Harassment or disrespectful conduct
- Misrepresenting this work as your own
- Attempting to circumvent the proprietary license

---

## Scope

This Code of Conduct applies to:

- GitHub repository interactions
- Issues and pull requests
- Any public mention or citation of this work
- Any collaboration under written agreement

---

## Enforcement

Violations will result in:

1. **First violation** — written warning
2. **Second violation** — permanent ban from repository
3. **IP violation** — legal action under
   Indian Copyright Act, 1957 and
   Berne Convention for the Protection of
   Literary and Artistic Works
